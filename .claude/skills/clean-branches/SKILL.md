# ブランチ整理

現在のリポジトリのローカルブランチのうち、main・develop 以外をすべて削除する。

## 保護対象（削除しないブランチ）

- `main`
- `develop`

## 手順

### 1. 現状把握

- `git fetch --prune` でリモートの状態を最新化する（マージ済み判定の精度を上げるため）
- `git branch --format='%(refname:short)'` でローカルブランチ一覧を取得する
- `git branch --show-current` で現在のブランチを確認する
- 保護対象を除いた削除候補の一覧を作る。候補が無ければ「削除対象なし」と報告して終了する

### 2. 現在ブランチの退避

現在のブランチが削除候補に含まれる場合：

- ワーキングツリーに未コミットの変更が無いことを `git status` で確認してから `main`（無ければ `develop`）へ checkout する
- 未コミットの変更がある場合は削除を中断し、状況をユーザーに報告する（stash や commit を勝手に行わない）

### 3. 削除の実行

削除候補を1本ずつ以下の順で処理する：

1. まず `git branch -d <ブランチ名>` を試す（マージ済みなら成功する）
2. `-d` が失敗した（未マージの）ブランチは**即座に `-D` しない**。未マージのブランチ名を列挙してユーザーに確認し、承認されたものだけ `git branch -D <ブランチ名>` で削除する

### 4. 報告

以下を簡潔に報告する：

- 削除したブランチ（マージ済み / 強制削除の別）
- 残したブランチとその理由（保護対象・ユーザーが削除を見送ったもの）

## 注意事項

- 削除するのはローカルブランチのみ。リモートブランチ（`git push --delete` など）は絶対に操作しない
- `main`・`develop` はいかなる場合も削除しない
- 未コミットの変更の退避（stash・commit）を勝手に行わない
