# ワークツリーの取り込みと削除

自分が起動したサブエージェントのワークツリーはユーザーが触らないので、確認なしで取り込み、削除まで済ませる（変更の残ったワークツリーは自動では消えない）。

## 手順

1. `git -C <ワークツリー> add -A` し、`git -C <ワークツリー> diff --cached --binary --no-renames HEAD` をスクラッチパッドにパッチとして保存する。`git -C <ワークツリー> rev-parse HEAD` を起点として控える
2. 元の作業ツリーの**ルート**で `git apply` する（サブディレクトリから当てると、その外のパスは黙って捨てられる）。当たらないファイルは `--exclude` で除いて残りを当て、除いたファイルは `git merge-file <元の作業ツリーのファイル> <起点の版> <ワークツリーの版>`（第 1 引数に書き込まれる）で 3-way マージする。衝突は両方の意図を残して解消する
3. 全部取り込んだら検証を通す。`git -C <ワークツリー> status --ignored --porcelain` で gitignore 対象のファイルが新しくできていないか確かめ、成果物があれば元の作業ツリーへコピーする（依存やビルドの生成物は除く）
4. `git worktree remove --force <ワークツリー>` と `git branch -d <ブランチ>` で消す

意図が両立しない衝突だけは消さずに残し、取り込み済みと未解決のファイルを分けて報告する。

ワークツリーの中から `.claude/setup.sh` 等のリポジトリ全体に効くスクリプトを実行しない（取り込んだ後に元の作業ツリーで実行する）。
