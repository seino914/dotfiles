# git pull（デフォルトブランチを最新化）

`bash ~/.claude/skills/git-pull/pull.sh` をカレントディレクトリで実行し、出力をそのまま報告する。

- git リポジトリの中ならそのリポジトリだけ、外なら配下（3 階層まで）のリポジトリすべてが対象
- 各リポジトリでデフォルトブランチへ切り替えて `git pull --ff-only` する。未コミットの変更があるリポジトリと、切り替えや pull で .gitignore 対象のファイル（例：手元の `.env`）が上書き・削除されうるリポジトリはスキップ、pull が通らない（fast-forward できない等）リポジトリは git のエラーを添えて失敗と出る。切り替えてから pull に失敗した場合は元のブランチ（detached HEAD なら元のコミット）へ戻し、戻せたかどうかも出る。ホームディレクトリとその上位（`/Users`・`/` 等）では実行を拒否する
- 出力は 1 リポジトリ 1 行。先頭記号は `✓` 更新・`=` 既に最新・`-` スキップ／失敗。ブランチを切り替えたときは `feature/x → main` のように元のブランチ名も出るので、報告でも省かずに伝える（元からデフォルトブランチなら `main` だけ）
- スキップ・失敗したリポジトリを自分で直そうとしない（stash・rebase・reset・追加の git 操作をしない）。理由を添えて報告するだけにする
