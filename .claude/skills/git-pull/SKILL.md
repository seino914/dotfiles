# git pull（デフォルトブランチを最新化）

`bash ${CLAUDE_SKILL_DIR}/pull.sh` をカレントディレクトリで実行し、出力をそのまま報告する。**Bash ツールの `timeout` は `600000` にして実行する**（配下のリポジトリが多いと既定の 120 秒を超えることがあり、途中で打ち切られると切り替え直後のリポジトリがデフォルトブランチのまま残る）。

- git リポジトリの中ならそのリポジトリだけ、外なら配下（3 階層まで）のリポジトリすべてが対象
- 各リポジトリでデフォルトブランチへ切り替え、upstream を fetch して `git merge --ff-only` で取り込む（`pull.rebase` 等の設定に左右されず、rebase はしない）。次のリポジトリはスキップする：detached HEAD のもの、別のリポジトリの中にある入れ子のもの（submodule・`vendor/` 等。外側から実行したとき）、未コミットの変更があるもの、切り替えや取り込みで .gitignore 対象のファイル（例：手元の `.env`）が上書き・削除されうるもの。取り込めない（fast-forward できない等）リポジトリは git のエラーを添えて失敗と出る。切り替えてから失敗した場合は元のブランチへ戻し、戻せたかどうかも出る。ホームディレクトリとその上位（`/Users`・`/` 等）では実行を拒否する
- 出力は 1 リポジトリ 1 行。先頭記号は `✓` 更新・`=` 既に最新・`-` スキップ／失敗。ブランチを切り替えたときは `feature/x → main` のように元のブランチ名も出るので、報告でも省かずに伝える（元からデフォルトブランチなら `main` だけ）
- スキップ・失敗したリポジトリを自分で直そうとしない（stash・rebase・reset・追加の git 操作をしない）。理由を添えて報告するだけにする
