# Claude Code 組み込みスラッシュコマンド一覧

Claude Code CLI にデフォルトで組み込まれているスラッシュコマンドのまとめ。
完全な一覧は公式リファレンス（<https://code.claude.com/docs/en/commands.md>）を参照。

## 会話・コンテキスト管理

| コマンド | 用途 |
|---------|------|
| `/clear` | 会話履歴をリセットして新しい会話を開始 |
| `/compact [指示]` | 会話履歴を要約してコンテキストを解放 |
| `/context` | 現在のコンテキスト使用状況をトークン数で表示 |
| `/resume` | 以前のセッションに戻る |
| `/rewind` | コードと会話を前のチェックポイントに巻き戻す |
| `/fork` / `/branch` | 会話を複製・分岐 |

## 設定・初期化

| コマンド | 用途 |
|---------|------|
| `/init` | プロジェクトの CLAUDE.md を生成 |
| `/config` | テーマ・モデルなどの設定を調整 |
| `/model` | 使用モデルを切り替え |
| `/effort` | 推論の努力レベルを設定 |
| `/memory` | CLAUDE.md（メモリファイル）を編集 |
| `/permissions` | ツール実行権限のルールを管理 |
| `/mcp` | MCP サーバー接続を管理 |

## レビュー・大規模作業

| コマンド | 用途 |
|---------|------|
| `/code-review [level] [--fix]` | 変更差分のコードレビュー（`ultra` でマルチエージェントのクラウドレビュー） |
| `/security-review` | セキュリティ脆弱性のチェック |
| `/plan` | プランモードで大きな変更を開始 |
| `/batch` | 複数エージェントで大規模変更を並列実行 |

## 診断・その他

| コマンド | 用途 |
|---------|------|
| `/doctor` | インストール・設定の診断と修正 |
| `/usage` | API 使用量・トークン消費の表示 |
| `/status` / `/tasks` | 処理状況の表示 |
| `/export` / `/copy` | 会話のエクスポート・応答のコピー |
| `/login` / `/logout` / `/help` / `/exit` | アカウント操作・ヘルプ・終了 |
